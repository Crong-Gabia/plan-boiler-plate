# Examples

This directory contains **filled-in example documents** for demonstration and reference.

- The boilerplate source-of-truth (SSoT) remains `product-description/**`.
- Anything under `examples/**` is **not** part of the template and should not be treated as canonical.

Tip: If you want to start from an example, copy the example’s folder contents into `product-description/**` in your own project/repo.
