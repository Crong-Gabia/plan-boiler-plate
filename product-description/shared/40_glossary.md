# 용어집 / Glossary

> 목적: 레퍼런스 조사/요구사항 작성 중 등장하는 **도메인 용어/정책 용어**를 한 곳에서 관리해 문서 간 용어 드리프트를 줄입니다.

## 사용 규칙(권장)

1) 문서에서 용어가 처음 등장할 때 1회만 링크(또는 한영 병기)한다.
   - 예: 훅(hook)
2) 이후에는 선호 표기(Preferred)를 사용한다.
3) 새 용어가 필요하면 이 문서에 먼저 추가하고, Source(근거 링크)를 남긴다.
