# 01. 제품 개요 (Product Brief)

상태: `DRAFT_FLOW`

작성일: 2026-01-30

## 1) 한 줄 정의

사내 구성원(필수)과 외부 게스트(옵션)가 **공통으로 가능한 시간대**를 투표/추천 기반으로 빠르게 모으고, 확정된 일정을 공유/캘린더 반영까지 이어주는 회의 시간 조율 서비스.

## 2) 문제 정의

- “가능한 시간 알려주세요”가 메신저/이메일로 흩어져 **수합 비용이 크다**.
- 시간대/근무 형태(재택/현장)로 **가용 시간이 복잡**해졌다.
- 외부 참석자(협력사/고객)가 섞이면 **권한/접근 경계**가 애매해진다.

## 3) 목표(Goals)

- 회의 시간 조율의 왕복 커뮤니케이션을 최소화한다.
- 사내 사용자(인증됨)와 외부 게스트(링크 기반)를 같은 플로우로 다룬다.
- 결정된 일정이 “공유”로 끝나지 않고, 최소한 **.ics** 수준으로 캘린더 반영 경로를 제공한다.

## 4) 비목표(Non-goals)

- 회의 안건/회의록/결정사항 관리(문서 협업)는 범위 밖.
- 참석자 ‘강제’ 스케줄 예약(자동 배정/강제 확정)은 v1 범위 밖.
- 복잡한 리소스 예약(회의실/장비/좌석 배정)은 v1 범위 밖.

## 5) 스코프(Scope)

### 5.1 포함

- **사내 사용자 + 외부 게스트 혼합 참여 지원** (DECISION-0001)
- 시간 후보(슬롯) 제안 → 참석자 가용성 응답 → 확정 → 공유

### 5.2 기본 가정(가변)

- 사내 사용자는 회사 인증(SSO/사번 계정 등)으로 로그인한다.
- 외부 게스트는 “초대 링크(토큰)”로 참여하며, 필요 시 이메일 기반 확인을 추가한다.

## 6) 사용자/역할

- Organizer(주최자): 폴 생성/초대/확정/삭제
- Internal Participant(사내 참석자): 로그인 후 응답
- Guest Participant(외부 참석자): 링크 기반 응답
- Admin(관리자): 외부 게스트 허용 정책/보관 기간/감사 로그 등 테넌트 정책

## 7) 핵심 개념(용어)

- Poll(조율 폴): 특정 회의/의사결정을 위한 시간 후보 모음
- Slot(시간 후보): 날짜+시간 구간(타임존 포함)
- Availability(가용성): 각 Slot에 대해 Yes/No/If-needed 등
- Workspace/Tenant(조직 단위): 사내 사용자/정책/데이터 소유권 경계

## 8) 성공 지표(예시)

- 폴 생성 → 확정까지 평균 소요 시간
- 폴당 평균 메시지 왕복(메일/메신저) 감소율
- 참여율(초대 대비 응답률), 외부 게스트 응답률
- “확정 후 캘린더 반영” 전환율(.ics 다운로드/연동 성공률)

## 9) 오픈 퀘스천

- 캘린더 연동 범위(읽기/쓰기)와 인증 방식(SSO) 확정 필요 (QUESTION-0001)
